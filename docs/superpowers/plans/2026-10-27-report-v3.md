# Chart report V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a birth rune chapter, a life path number chapter, a "Where they agree" part, love and work questions and a "Try this week" line to the paid report, and remove the Patterns page.

**Architecture:** The rune and the number are pure date maths in a new Node module (`birthsigns.mjs`), called by `facts.mjs`, so they arrive in FACTS like every other computed value. All meanings are new closed-book entries in `library.json`. `build_report.py` prints the library text; the writer adds only cited sentences; `validate.py` checks them.

**Tech Stack:** Node 20+ (ESM, `node:test`), Python 3.14, reportlab, pypdf, pytest.

**Spec:** `docs/superpowers/specs/2026-10-27-report-v3-design.md`

## Global Constraints

- The GitHub repo is PUBLIC: never commit real birth data. Tests use only `samples/demo-*.json`. Owner data stays in `private-files/report-samples/` (git-ignored).
- Do not push or merge. Commits stay local on `feat/chart-tools`.
- Rune table: the Pagan Pages table in the spec, verbatim, one rune per day. Rune spellings: Fehu, Uruz, Thurisaz, Ansuz, Raidho, Kenaz, Gebo, Wunjo, Hagalaz, Nauthiz, Isa, Jera, Eihwaz, Perthro, Algiz, Sowilo, Tiwaz, Berkano, Ehwaz, Mannaz, Laguz, Ingwaz, Othala, Dagaz.
- No hour rune.
- Life path method `reduce-parts`: reduce month, day, year separately (keep 11, 22, 33), add, reduce again (keep 11, 22, 33).
- All new text: reading grade ≤ 8, ≤ 22 words a sentence, no banned words, no "will" predictions, no health/money/legal words, no ritual or magic promises, no "you should" advice.
- "Nie powtarzaj się": the 4-word repeat check stays an error.
- A heading never ends a page (`keep_heads()`, `Layout` tests).
- Body text 13 pt, existing styles only.
- New library texts are drafts until the owner approves them. `_about` of each new section says "DRAFT, not approved" until then.

## Review Focus

1. Sun and Moon (or Rising) in the same sign: the "Try this week" step must not print the same line twice (repeat rule). → test in Task 5.
2. Birth on 29 February: rune and life path must both work (Tiwaz; day 29 → 11 kept). → tests in Task 1.
3. A birth date where the Vogue table gives two runes (the first day of each rune, and 12–13 Feb): the edge line shows; 1 Oct shows none. → tests in Task 1, print test in Task 5.
4. `agree` empty: the report prints the fixed line and the validator accepts an `agree` section without theme names. → tests in Tasks 3 and 4.
5. The writer names a rune or a life path number that is not in FACTS (for example "your rune Wunjo" for a Gebo chart): validator error. → test in Task 4.
